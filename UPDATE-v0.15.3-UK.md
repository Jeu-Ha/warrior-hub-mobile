# Desktop 5.20.5 / mobile 0.15.3

Кнопку Unlock input прибрано. Застаріле стеження за пером більше не може блокувати всі елементи програми: захист долоні під час активного письма збережено, а натискання звичайного елемента керування автоматично завершує залишений контакт пера зі збереженням прийнятих штрихів. Події завершення контакту, втрати захоплення, фокуса й автоматичне резервне відновлення залишаються активними.
